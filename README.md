# Premere in caso di dubbi

Interactive web page built with plain HTML, CSS and JavaScript. It has a background video (desktop and mobile versions) and a central button that shows a popup with a random phrase, with no repeats until all have been shown. Each phrase can include an image or a video.

The assets folder is not included: add your own files using the names listed in assets/README.md. The phrases can be edited in script.js, in the FRASI list, and each one can have an image (img) or a video (vid).
